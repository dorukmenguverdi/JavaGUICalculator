# Java GUI Calculator

A simple Java-based calculator with a graphical user interface (GUI) using Swing. The calculator supports basic arithmetic operations such as addition, subtraction, multiplication, and division. This project demonstrates the usage of Java Swing components and object-oriented programming (OOP) principles to build a functional desktop application.

## Features

- **Basic Arithmetic Operations**: Addition, subtraction, multiplication, and division.
- **Clear Functionality**: Reset the calculator with the "C" button.
- **Error Handling**: Handles errors such as division by zero and invalid input.

## Requirements

- **Java**: The project is built using Java 8 or higher.
- **Swing**: The project utilizes Java Swing for the graphical user interface.

## How to Run

1. Clone the repository:
git clone https://github.com/dorukmenguverdi/JavaGUICalculator.git

2.Compile the Java files:
javac *.java

3.Run the program:
java CalculatorApp
